## Run

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) copies the bundled `entry.png` to the output directory. The image itself is drawn by `make_image.py` (PIL) with no external images and no network.
